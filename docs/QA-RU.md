# Проверка поставки — 6 сентября 2026 года

## Фактический результат

Локальные проверки: **57/57 пройдены**. В их число входят 24 проверки ширины страницы: EN и FR на 320, 360, 375, 390, 430, 720, 768, 820, 1024, 1280, 1440 и 1920 px. Отдельно выполнены `npm ci`, `npm run build`, синтаксическая проверка JavaScript и Bash.

**Важно о методе:** HTTP-сервер проверен запросами Python. Переход Chromium на локальный HTTP-адрес заблокирован политикой среды (`ERR_BLOCKED_BY_ADMINISTRATOR`); ограничения браузера не изменялись. Интерфейс проверен отдельно загрузкой предоставленного самодостаточного HTML в память Chromium, без сетевого доступа к заблокированному адресу. Это не end-to-end-проверка опубликованного сайта.

Подтверждено: HTTP 200 главной страницы; HTTP 404 для неизвестных и служебных путей; защитные заголовки; отсутствие переполнения по горизонтали на перечисленных ширинах; мобильное меню и закреплённая кнопка; EN/FR; VIP-вкладки и клавиатура; открытие/закрытие диалогов; FAQ; блокировка перехода для ON и OTHER; необходимость выбора провинции и подтверждения возраста; сброс подтверждения при смене провинции; фиксированная партнёрская ссылка; событие `affiliate_outbound` в памяти; отсутствие ошибок JavaScript и внешних загрузок в проверенном in-memory-сеансе.

Внешний переход был предотвращён тестом. Регистрация, депозит, передача персональных данных и рекламные расходы не выполнялись.

## Что не подтверждено

Не проверены опубликованный домен, HTTPS/DNS после деплоя, удалённый запуск GitHub Actions, фактическая атрибуция в партнёрском кабинете, сохранение языка после HTTP-перезагрузки, UTM в HTTP-странице, реальное устройство iPhone, IP-геоблокировка и юридическая приёмка. Автоматические тесты не заменяют эти проверки.
