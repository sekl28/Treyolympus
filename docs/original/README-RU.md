# Stake Canada — North

Самодостаточный адаптивный лендинг: `index.html`. Внешние библиотеки и шрифты не требуются.

## Настроено
- Партнёрская ссылка: https://stake.com/?c=NE3yHgEO — извлечена из предоставленного webarchive.
- EN / FR: переключатель, поддержка `?lang=fr`, язык запоминается в sessionStorage текущей вкладки.
- Мобильная закреплённая кнопка, доступная навигация, VIP-вкладки, FAQ.
- Перед переходом: самостоятельное подтверждение возраста 19+, выбор провинции. Онтарио и другие страны блокируются интерфейсом. Это НЕ IP-геоблокировка и НЕ KYC.
- Privacy / affiliate disclosure; нет рекламных пикселей, чужих аналитических библиотек, платёжных форм или сбора документов.
- События в `window.dataLayer`: `landing_view`, `stake_click_intent`, `vip_tier_view`, `affiliate_outbound`. Без подключённой аналитики события существуют лишь в памяти страницы: на сервер ничего не отправляется.
- UTM source / medium / campaign попадают только в события dataLayer. Код c фиксирован; параметры URL не могут заменить партнёрский код.

## Перед платным запуском
1. Подтвердить с партнёрским менеджером Stake право на такой трафик, допустимые GEO и рекламные материалы. Возраст в этом лендинге намеренно 19+ для всей аудитории.
2. Провести правовую проверку по выбранным провинциям. Доступность сайта не означает местную лицензию. Онтарио исключить в рекламе и на уровне инфраструктуры; форма — лишь дополнительная проверка.
3. Проверить выбранную рекламную платформу: допуски к азартным играм, сертификацию и правила бонусной рекламы. Одобрение рекламы не обещано.
4. По необходимости подключить согласованный рекламный пиксель с подходящей политикой приватности и управлением согласием. Скрипт не содержит пикселей из других проектов.
5. После правовой и технической приёмки снять noindex/nofollow: метатег в index.html, robots.txt, X-Robots-Tag в vercel.json. Пока это контролируемая версия для просмотра.

## Размещение
Содержимое каталога можно разместить на любом статическом HTTPS-хостинге. Для Vercel — Other / Static, без build-команды, корневой каталог. Не загружать рядом архив пользователя с данными и рабочие тесты.

## Проверка заявлений
Ссылки на официальные источники находятся в раскрывающемся блоке внизу страницы. Проверено 6 сентября 2026 года.
- Нет гарантии моментальных выплат: сеть, KYC и ручная проверка крупных сумм могут задерживать вывод.
- Interac: до 3 рабочих дней согласно справке Stake.
- Бонусы: по условиям и статусу. Нет выдуманного welcome-бонуса или гарантированного процента возврата.
- VIP-хост: начиная с Platinum IV по условиям оператора.
- Лимиты: различаются по играм, валютам и рынкам. Нет обещания безлимитных ставок.
- Сайт не выдаёт себя за официальный сайт Stake.

## Проверка ссылки
Вставка параметра c подтверждена на уровне кода. Фактическое засчитывание регистрации/депозита можно подтвердить только по данным партнёрского кабинета Stake; такой проверки в этой сборке не проводилось.
